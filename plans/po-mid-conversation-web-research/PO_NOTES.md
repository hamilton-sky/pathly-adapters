# PO Notes — po-mid-conversation-web-research

_Last updated: 2026-05-12_

## Who Is This For

The PO agent itself. It talks directly to the user while simultaneously needing external
knowledge (market context, regulations, competitors, pricing, terminology). It is the only
agent in the flow that needs research *during* a live conversation rather than before it.

## Definition of Success

The user notices the PO found something they didn't know — the web search itself delivers
value inline in the conversation thread, surfacing risks or context the user hadn't considered.

## Out of Scope

- Codebase scouts (type: scout / type: quick) — strictly type: web only
- Pre-session research phase (no phase: analyze split)
- Any changes to skills/po.md — agent-only change
- Any other agent contracts

## Constraints

None.
