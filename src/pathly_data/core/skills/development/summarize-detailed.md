# summarize (detailed)

Produce a **detailed summary** of the source document: for each major section, write a line
with the section's topic AND its key points or decisions — not just the heading. Capture
specifics (names, APIs, identifiers, decisions, sequence) so the summary is findable by
concrete terms. Output only the section lines, no preamble. Optimizes for recall: the artifact
will surface for queries about any of its sections.
