+
Assembly flow bar

Shows HOST → AGENT → SKILL chain at a glance so users understand how the three selectors compose the final prompt. Color-coded per group type.

A
Per-group active colors

Host = cyan, Agent = purple, Skill = green. Each section has its own accent so the active selection reads at a glance even when scrolling fast.

B
Section label divider line

Horizontal rule extends from each label to the right edge — groups sections without adding heavy borders or extra padding.

+
Prompt header bar

"modified from default" badge turns orange when the prompt differs from its skill source. A copy button lets users grab the full prompt without scrolling.

C
Syntax-highlighted prompt

Heading lines in accent, meta lines muted, bullet values in green. Makes the prompt structure scannable without needing a full code editor.

×
Drop: gray-on-gray active chip

Current active chip uses a single accent border with a near-invisible tinted bg. Replace with distinct color per group + checkbox icon so active state is unambiguous.

A
Full phase names in timeline

Replace "STORMI→BUILDI" truncations with full names (Storming, Planning, Design…) — the dots are now 30px with room for 56px labels. The font already fits at 9.5px mono.

B
Stats: sparkline + sub-label

Each stat card gets a thin progress bar showing % of budget/cap used, and a second-line detail (e.g. "in 41k · out 47k", "est. $0.08 remaining"). Replaces the isolated large numbers.

+
Phase filter pills in tab bar

Quick filter to show only events from a specific stage (build, review…). Replaces the vague "all phases" text that currently sits in the far right corner.

C
Actor column in event log

Splits the currently long detail strings — role name (planner, builder, FSM) goes in its own column in purple so you can scan who triggered each event without parsing text.

+
Inline cost chip on AGENT_DONE

Green "$0.25" chip directly on the row replaces the raw text — matches the green cost stat card and makes cost scannable without reading the full detail string.

D
Token I/O bar in footer

Replaces "in/out →↓" text with a split bar (blue=in, green=out) + labels. Shows token distribution at a glance without enlarging the footer.
