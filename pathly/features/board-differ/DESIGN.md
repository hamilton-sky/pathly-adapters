## Component Design Specifications

### 1. "See Changes" Pill on Artifact Card

The entry-point trigger that opens the diff modal.

```
Artifact card row
┌─────────────────────────────────────────────────┐
│ 📄 path/to/file.py               [See changes ▸] │
└─────────────────────────────────────────────────┘
```

- **Pill state — active** (file is modified vs HEAD):
  - Background: `var(--color-primary)` (`#1E293B`)
  - Border: `1px solid var(--color-accent)` (`#22C55E`)
  - Text: `var(--color-accent)`, 12px IBM Plex Sans Medium
  - Icon: `GitDiff` (Lucide), 14px, `currentColor`
  - Hover: border opacity 0.8, background lightens to `#253045`
  - Transition: `150ms ease-out` on background/border

- **Pill state — disabled** (file clean / not tracked):
  - Background: transparent
  - Text: `var(--text-muted)`, opacity 0.4
  - No border, `cursor: not-allowed`

- **Touch target**: min-height 28px, horizontal padding 10px (visual); underlying button is always ≥ 44px tall to meet the touch target rule via negative margin or `hitArea` wrapper.

### 2. RawCodeDiffView — Split Diff Modal

The primary diff surface (surface a). A modal dialog, not a panel replacement.

**Layout: 2-column flex row (split), or single column (unified toggle)**

```
╔══════════════════════════════════════════════════════════════════╗
║  path/to/file.py  [Split | Unified]  [⊠ Close]                  ║
╠══════════════════════════════════════════════════════════════════╣
║  BASE (HEAD)                │  CURRENT (working tree)            ║
║  ─────────────────────────  │  ────────────────────────────      ║
║  12  def foo():             │  12  def foo():                    ║
║  13      old_logic()        │ [+] 13      new_logic()            ║
║ [-] 14      return x        │  14      return y                  ║
╠══════════════════════════════════════════════════════════════════╣
║  [▼ Impact Panel — 3 callers affected]                           ║
║   • src/bar.py::bar()    [callers: 2]  →  open in editor         ║
║   • tests/test_foo.py::test_foo()  [direct]  →  open in editor  ║
╚══════════════════════════════════════════════════════════════════╝
```

**Modal chrome:**
- Background: `var(--color-background)` (`#0F172A`)
- Border: `1px solid var(--color-border)`
- Border-radius: `8px`
- Box-shadow: `0 24px 48px rgba(0,0,0,0.6)` (deep OLED shadow)
- Max-width: `min(90vw, 1200px)`; max-height: `85vh`; overflow: `hidden` (inner panels scroll)
- Scrim: `rgba(0,0,0,0.55)` over board surface (meets 40–60% modal legibility rule)

**Header bar (32px):**
- File path in `JetBrains Mono` 13px, `var(--color-foreground)` truncated from left
- Split/Unified toggle: two `<button>` pills, active gets `background: var(--color-primary)`, inactive is ghost
- Close button: `X` icon, 28px tap target, keyboard-dismissable (Escape)

**Diff gutter (line numbers):**
- Width: 48px; text: `JetBrains Mono` 11px, `var(--color-muted)` (`#272F42`→ muted text tone)
- Separator: `1px solid var(--color-border)` vertical
- Added line background: `rgba(34, 197, 94, 0.12)` (accent green, 12% opacity)
- Removed line background: `rgba(239, 68, 68, 0.12)` (destructive red, 12% opacity)
- Added inline token: `rgba(34, 197, 94, 0.25)` background highlight on changed chars
- Removed inline token: `rgba(239, 68, 68, 0.25)` background highlight on changed chars
- `+`/`−` prefix: `JetBrains Mono` 12px in respective accent/destructive color
- Unchanged lines: no background, foreground text `var(--color-foreground)` at 80% opacity

**Split columns:**
- `flex: 1; min-width: 0` on each half — always resize (Studio responsiveness rule)
- Divider: `1px solid var(--color-border)` vertical — `flex-shrink: 0`
- Horizontal scroll within each column: `overflow-x: auto`, not the outer modal
- Font: `JetBrains Mono` 13px, line-height 1.6 (readable in code context)
- Tab size: 2 (CSS `tab-size: 2`)
- Virtualize diff rows if file > 200 lines (>200 rows use windowed rendering per `virtualize-lists` rule)

### 3. Impact Panel (subordinate / collapsible)

Sits below the diff, defaulting to **collapsed** (36px rail).

```
[▼ Impact — 3 callers affected]        ← collapsed rail, 36px
```

Expanded (max-height: 200px, overflow-y: auto):

```
[▲ Impact — 3 callers affected]
─────────────────────────────────────────────────
  src/bar.py :: bar()          callers: 2  [→]
  tests/test_foo.py :: test_foo()   direct  [→]
  src/qux.py :: qux()          callers: 1  [→]
```

**Rail (collapsed):**
- Height: 36px; background: `var(--color-muted)` (`#272F42`)
- Border-top: `1px solid var(--color-border)`
- Label: IBM Plex Sans 12px Medium, `var(--color-foreground)` 70%
- Count badge: `background: var(--color-secondary)`, 18px pill, IBM Plex Sans 11px

**Expanded rows:**
- Row height: 36px, `align-items: center`, `padding: 0 12px`
- Symbol name: `JetBrains Mono` 12px, `var(--color-foreground)`
- Relation label (`callers: N` / `direct`): IBM Plex Sans 11px, `var(--color-foreground)` 50%
- Arrow button `→`: ghost icon button, 28px, shows on row hover (CSS `:hover` — same element, no JS)
- Hover row background: `rgba(255,255,255,0.04)` (4% white lift — matches Studio's card hover convention)
- Zero results: "No callers found" empty state, 12px muted text, centered

**Animation:**
- Collapse/expand: `max-height` transition `250ms ease-out` (no `height` animation — matches `transform-performance` rule)
- `prefers-reduced-motion`: instant switch, no transition

### 4. Diff Modal Accessibility & Keyboard

| Action | Keyboard |
|---|---|
| Open "See changes" | `Enter` / `Space` on pill |
| Close modal | `Escape` |
| Toggle Split/Unified | `Tab` to toggle buttons, `Space` |
| Scroll diff | Arrow keys when diff panel focused |
| Expand/collapse Impact | `Enter` / `Space` on rail |
| Navigate Impact rows | `↓`/`↑` arrow keys |
| Jump to file (Impact row) | `Enter` on row |

- Modal traps focus (`aria-modal="true"`, `role="dialog"`) until dismissed
- Focus returns to the "See changes" pill that triggered it on close
- `aria-label` on icon-only buttons (close, split/unified)
- Split diff columns: `role="region"` with `aria-label="Base (HEAD)"` / `aria-label="Current changes"`
- Diff rows: `role="row"` on each line; added/removed announced via visually-hidden `+ ` / `- ` prefix text

---

### 5. Responsive Behaviour

| Viewport | Diff layout |
|---|---|
| ≥ 900px | Split (default) — two columns |
| 600–899px | Unified (auto-switched, toggle still available) |
| < 600px | Unified, modal full-width (`width: 100vw`, no border-radius) |

Board panel width at ≤ 200px: "See changes" pill collapses to icon-only (`GitDiff` 14px). No overflow.

## Pre-Delivery Checklist

- [ ] No emojis as icons — use Lucide (`GitDiff`, `ChevronDown`, `X`, `ArrowRight`)
- [ ] Diff line backgrounds use rgba overlays, not new CSS variables (extend existing tokens)
- [ ] `min-width: 0` on all flex children in split columns and diff rows
- [ ] `overflow-x: auto` on each diff column, not the modal
- [ ] Added/removed line colours meet 3:1 contrast on dark background (visual indicator, not text)
- [ ] Impact panel rows have ≥ 44px effective tap targets (row hover extends full width)
- [ ] Escape closes modal; focus returns to trigger
- [ ] `prefers-reduced-motion` removes Impact panel height transition
- [ ] Virtualize diff rows for files > 200 lines
- [ ] RawCodeDiffView uses `JetBrains Mono`; no inline `style={{}}` — font set via `.module.css`
- [ ] Colour tokens reference existing CSS custom properties from `tokens.css` where they already exist; only the diff-specific rgba overlays are new
