# Design System — board-grid

> Generated by UI UX Pro Max · Stack: react (Electron renderer, CSS Modules, tokens.css) · 2026-07-06

## Query
A 4th "All" tab in the Command Center CommsPanel that renders every board item as compact, kind-banded tiles (Goals → Tasks → Messages → Artifacts) with a responsive container-query grid layout — dashboard/tool product type for the react stack.

---

## Design System Output

### Pattern
- **Name:** Dashboard Tool — Kind-Banded Tile Grid
- **Conversion Focus:** Inventory overview — show everything at a glance, click-to-detail.
- **CTA Placement:** Each tile is the CTA (click → opens the appropriate detail modal).
- **Color Strategy:** Neutral dark surface; kind accent via left border bar (`data-type` + `tokens.css` vars); badge carries the semantic color (re-used from `MessageTypeBadge`).
- **Sections:** 1. Band header (label + count, sticky), 2. Responsive tile grid (container-query), 3. Placeholder banner (≤220px).

### Style
- **Name:** Flat Design / Information-Dense Dashboard (Touch-First, no-shadow)
- **Mode Support:** Inherits the existing Studio light/dark token system — no new mode logic needed.
- **Keywords:** flat, 2D, no shadow, compact tiles, color-blocked accents, geometric, precision, icon + label, keyboard-navigable
- **Best For:** System UI, information-dense dashboards, admin panels, multi-kind inventory views
- **Performance:** Excellent — no GPU blur/shadow effects; container-query driven reflow.

### Colors — use existing `tokens.css` vars only, no new hex values

All colors come from the Studio token system. No raw hex is introduced in the new component family.

| Kind / Role | Token | Usage |
|---|---|---|
| Goal | `var(--blue)` | Tile left border accent |
| Task | `var(--purple)` | Tile left border accent |
| Artifact | `var(--runtime)` | Tile left border accent |
| Decision / Nudge | `var(--accent)` | Tile left border accent |
| Question | `var(--yellow)` | Tile left border accent |
| Answer | `var(--green)` | Tile left border accent |
| Warning | `var(--orange)` | Tile left border accent |
| Escalation | `var(--red)` | Tile left border accent |
| Discovery | `var(--blue)` | Tile left border accent |
| Status / Phase / Note | `var(--text-muted)` | Tile left border accent |
| Tile surface | `var(--bg-surface1)` | Tile background |

### Typography — inherit Studio type scale
- Body / meta: project's existing body size (~12–13px in dense UI) — do not set a new font-size; inherit from `.view` root.
- Tile title: 2-line clamp via `-webkit-line-clamp: 2` + `display: -webkit-box` + `overflow: hidden`.
- Band header label: use existing heading weight/size tokens (e.g. `font-weight: 600`, `font-size: 11px` uppercased label style matching other panel headers in Studio).
- Count suffix (e.g. "Goals · 3"): muted, same size as header, `var(--text-muted)`.
- Meta row: 10–11px, `var(--text-muted)`, `white-space: nowrap; overflow: hidden; text-overflow: ellipsis`.

### Spacing — 4/8px grid
- Tile internal padding: `8px` (2 × 4px base)
- Tile gap in grid: `var(--space-2)` (8px, matching the existing Studio spacing token)
- Band section gap (between bands): `16px` (`var(--space-4)`)
- Band header padding-block: `6px 4px`
- Left accent border width: `3px`

### Responsive Grid — container-query (per band)

The `container-type: inline-size` goes on each `.grid` element (the tile wrapper within each band), **not** on the band `<section>` or the scroll root.

```css
/* GridView.module.css */
.view {
  overflow-y: auto;
  overflow-x: hidden;
  height: 100%;
}

.band + .band {
  margin-top: 16px;
}

.bandHeader {
  position: sticky;
  top: 0;
  z-index: 1;
  background: var(--bg-surface1);
  padding: 6px 0 4px;
  font-weight: 600;
  font-size: 11px;
  text-transform: uppercase;
  letter-spacing: 0.04em;
  color: var(--text-muted);
}

.grid {
  container-type: inline-size;
  container-name: gridband;
  display: grid;
  grid-template-columns: 1fr;       /* <400px: 1 column */
  gap: var(--space-2);
}

@container gridband (min-width: 400px) {
  .grid { grid-template-columns: repeat(2, minmax(0, 1fr)); }
}
@container gridband (min-width: 600px) {
  .grid { grid-template-columns: repeat(3, minmax(0, 1fr)); }
}
```

- `minmax(0, 1fr)` (not `1fr`) prevents column blowout from long unbroken tile titles.
- Sticky band headers sit on the `<section>`, **outside** the query container — containment does not clip them.
- At ≤220px: `ResizeObserver` on the `GridView` root switches to a `<PlaceholderBanner>` ("Panel too narrow — widen to see the grid"), keeping `overflow: hidden` on the root at all times.

### Key Effects
- Immediate press feedback on tiles: `scale(0.97)`, `transition: transform 150ms ease-out` — no layout shift.
- Zero elevation / no box-shadow — flat style.
- Color accent: left-border 3px solid `data-type`-matched token (no background tint on the tile itself).
- Band header sticky: `position: sticky; top: 0` inside the scroll container; `z-index: 1` to clear tile content.
- Tile hover: `background: var(--bg-surface2)` (or equivalent hover surface token) + `cursor: pointer`.
- Focus ring: `outline: 2px solid var(--accent); outline-offset: 1px` — never `outline: none`.
- Modal open: inherits existing `ArtifactModal` / `GoalDetailModal` portal + backdrop pattern — no new motion spec needed.

### Icons
- Use `lucide-react` exclusively, matching existing Studio icon style (stroke, not filled).
- `LayoutGrid` (size 12) for the "All" tab toggle button.
- `X` (size 15) for the `MessageDetailModal` close button.
- No emoji anywhere.

### Avoid (Anti-patterns)
- Raw hex values in component files — use `tokens.css` vars only.
- `style={{}}` inline styles — zero allowed in this component family.
- `overflow: visible` on the scroll root or tile grid.
- `1fr` without `minmax(0, 1fr)` in grid columns.
- `container-type` on the band `<section>` or scroll root (breaks sticky headers and causes containment bugs).
- Sorting or filtering within the band — the "All" tab is a flat inventory; sort belongs in `gridBands.ts` as a future P2 addition.
- `focus: outline: none` without a visible replacement.
- Box-shadows or `backdrop-filter` — this is a flat-design surface.

## UX Guidelines Applied

| Rule | Application |
|---|---|
| `keyboard-nav` | Every tile is `<button type="button">` — Tab-navigable, Enter/Space to open. |
| `focus-states` | 2px solid `var(--accent)` ring, offset 1px — visible in all themes. |
| `touch-target-size` | Tile is a full `<button>` spanning its grid cell — meets 44×44pt minimum. |
| `color-not-only` | Kind distinguished by left-border color **and** `MessageTypeBadge` (text + color). |
| `horizontal-scroll` | `overflow-x: hidden` on `.view`; `minmax(0, 1fr)` on grid columns; no fixed widths. |
| `min-width: 0` | On all flex children inside tiles and meta rows — prevents overflow. |
| `reduced-motion` | Scale feedback and any future entrance animation must wrap in `@media (prefers-reduced-motion: no-preference)`. |
| `virtualize-lists` | Not in P1 scope — boards are typically <200 items. Add if profiling shows jank. |
| `loading-states` | Not applicable — grid reads from the already-hydrated `messages` prop; no new fetch. |
| `empty-states` | If all 4 bands are empty (no messages at all): render a single "No board items yet" centered message. Empty individual bands are omitted silently. |
| `modal-escape` | All three modals (GoalDetailModal, ArtifactModal, MessageDetailModal) support Escape-to-close. MessageDetailModal uses `useFocusTrap`. |
| `content-priority` | Bands ordered Goals → Tasks → Messages → Artifacts. Empty bands omitted — no visual noise. |
| `truncation-strategy` | Title truncated to 2 lines via CSS clamp; full title visible in the detail modal. |
