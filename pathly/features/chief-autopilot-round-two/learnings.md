# Learnings: chief-autopilot-round-two

Things a fresh worker would otherwise waste time rediscovering: a command that works, a
trap, a quirk of the environment. Append one or two lines, newest last, tagged with your
ticket number. Never edit or delete another line. Keep it short; a human prunes it.
- (01) `python scripts/gen_test_index.py --check` goes stale when you add a test to an existing file too (the INDEX counts tests): rerun the generator after any test edit.
- (02) To prove a consult without a spawn host, pass `spawn_fn` that `eventlog.append_event`s an AGENT_DONE carrying the given `run_id`, and call `start_consult(..., block=True)`. A parked single-run task has no claim, so `asking_task` misses it: read the route's `task_id`.
- (02) The provenance scan in `tests/comms_board/test_comms_provenance.py` rejects any `post_message` with a non-constant `author_*` keyword: a server row authored as a role goes through a named stamp (`consult_stamp`), and changing `tests/comms_board/test_comms_provenance.py` changes `tests/comms_board/INDEX.md` too.
- (02) A test that monkeypatches `consult_routes.routes_for_questions` (to fake a racing caller) must `monkeypatch.undo()` before reading the route back with the same function.
- (03) A consult test that needs git measuring builds its own repo under `tmp_path` (`git init`, a tracked file, one commit): `proof/tree.snapshot` returns None unless the project root is the git top, so 02's plain `tmp_path` project always takes the "not measured" path.
- (03) With `PATHLY_RUNNER_EARLY_ADVANCE` on, `_run_stage_via_terminal` returns on AGENT_DONE while the PTY runs and leaves the run in `supervisor/registry` until the PTY reports; `registry.get_run(run_id)` after the return is None only once the process exited. To test it, monkeypatch `supervisor.terminal._run_stage_via_terminal` with a fake that `create_run`s and later `mark_pty_result`s on a thread.
- (04) A test that posts a role question with a spawn host registered starts a real consult unless it monkeypatches `supervisor.consult_router.start_consult`; `consult-` threads are not in the chief guard, so join them yourself. `monkeypatch.undo()` also undoes conftest's home patch (the DB moves): restore one attribute with `setattr` instead.
- (04) A test that posts a role question must mint its run token with the post body's board and scope and a project root: the router takes all three from the token and hands a mismatch to the person.
- (04) `tree.snapshot` fails (None, "could not be snapshotted") when the event mirror flusher's `EVENTS.tmp` + `os.replace` in a storage folder inside the repo lands during `git add -A` (`fatal: unable to stat ... EVENTS.tmp`): a rare flake in tests whose feature folder is in their git repo (`tests/fsm_flows/review_packet_support.py`), not a regression.
- (05) To hit the park/answer race, monkeypatch `db.queries.task_waits.open_questions_by_run` with a wrapper that posts the answer after the real read (both park sites import it lazily). To see a released loop task still `pending`, pass `scheduler_loop(abort_check=lambda: bool(spawns))`, or the next frontier read claims it again. orchestrator.py is at 400 lines.
- (06) To test a drain's consult wait, spy on `supervisor.consult_wait.wait_for_consults` (fan_out calls it through the module) and answer from a thread once the spy fires; lower `consult_wait.POLL_INTERVAL`/`WAIT_TIMEOUT` with monkeypatch. A successful goal-loop run ends `state.status == "done"`.
- (06) A role-question test that asks on every attempt never finishes against unfixed code: _run_goal_loop's 120 s wait fails with a 50 MB assertion message (the prompts); grep the summary line. answer_question stamps no author_run_id.
- (06) To show the event-mirror race on demand, run a test under a scratchpad pytest plugin (PYTHONPATH=<dir> -p <plugin>, conftest isolation intact) that wraps `fsm.gates.floor.tree.snapshot` with a thread looping EVENTS.tmp write + os.replace in the repo's feature dir: snapshot returns None (git 128 'unable to stat'), floor_gate skips.
- (07) Regenerate golden snapshots with `PYTHONPATH`-free `sys.path[:0]=["src","tests"]; from pathly_orchestrator.compose import compose_skill; from _paths import SNAPSHOT_DIR` (the module is `pathly_orchestrator.compose`, not `pathly_data`). A role question posted in a test with no spawn host stays as posted (`no_host`), so the test answers it itself.
- (08) The provenance scan accepts only the literal `**stamp(caller_identity(request))` in a `post_message` call: hoisting the identity into a variable fails `test_every_post_message_call_is_stamped_or_on_the_allow_list`. A chief-token `/comms/post` test needs a `chief_sessions` row (`db.queries.chief.create_session`), `project_root` and `"from": "chief"`.
- (11) The provenance scan also refuses any `author_*` string literal outside `db/` (`test_no_author_value_is_hard_coded_outside_the_db_constants`): take the role from the token's identity or a `db/provenance_values` constant.
- (14) The trust-screen fixture is measured, not the issue quote: claude 2.1.319 under `env -i HOME=<fresh temp> PATH=/opt/node22/bin:/usr/bin:/bin TERM=xterm-256color` (seed `~/.claude.json` with `{"hasCompletedOnboarding":true}` or it shows the theme picker) reaches the trust screen with no login; its cursor starts on "No, exit" and it draws words with `\x1b[NG`, so stripped text has no spaces.
- (14) studio/node_modules/node-pty loads under plain node, so `npx esbuild <file>.ts --bundle --platform=node --format=cjs` plus a node-pty script drives a real CLI through a main-process module; `__dirname` works in a main-process vitest test, `new URL(..., import.meta.url)` does not (jsdom).
- (15) claude path rules: `Read(/x/**)` anchors at the settings source, `Read(//x/**)` is the filesystem root (permissions docs). A chief test that needs the hook secret claims it once (`chief_secret_claim.claim` or `POST /chief/hook-secret`); a second claim closes the chief, so cache it (`chief_acceptance_support.hook_secret`).
- (16) To bill a consult end to end in a test, give `start_consult` a `spawn_fn` that calls `consult_run._default_spawn(**kwargs)` with `broadcast_fn` replaced by a host (mark_started + mark_pty_result with a billed `result`) and set `PATHLY_RUNNER_EARLY_ADVANCE=0`: the slow path writes the synthetic AGENT_DONE and BILLING_UPDATE before it returns, with no thread left running.
- (09) A view that reads a new query key fails `test_chief_gate_keys.py` unless `http_server/chief_field_reads.py` lists it (or `not_for_chief`), and a chief token sending it gets 403: put that file in Touches. The Operator text is at 3997 of its 4000-character limit.
- (17) `python -m pytest tests/http_api tests/comms_board` takes ~20 min here (4193 tests): run it in the background rather than in the foreground with the 10-min tool limit.
