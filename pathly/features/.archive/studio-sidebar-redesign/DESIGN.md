## Drag Affordance Spec (Conv 3)

- `draggable="true"` on card root element
- `onDragStart`: `e.dataTransfer.setData(PATHLY_DRAG_MIME, JSON.stringify({dragType:'canvas', name, section, path}))`
- For nested items inside a flow: `e.stopPropagation()` to prevent parent drag capturing
- `cursor: grab` via `.libraryCard[draggable="true"]` selector
- No custom drag ghost needed — browser default is acceptable
