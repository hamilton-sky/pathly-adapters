# Design System — cli-command-center

> Generated by UI UX Pro Max · Stack: react (Electron renderer) · 2026-07-05

## Query
CliMonitorBar CLI Command Center panel — floating sidebar panel with flow controls, engine queue list, and expandable north-star modal design system for react stack

## Design System Output

### Pattern
- **Name:** Developer Tool Panel (floating sidebar + expandable modal)
- **Conversion Focus:** Embedded live-state monitor. Show engine status, queue depth, and flow stage at a glance.
- **CTA Placement:** Primary action (Run/Stop) pinned to top of panel; secondary actions (expand, kill) inline with rows
- **Color Strategy:** Dark OLED base with green accent for success/running states; destructive red for kill/error
- **Sections:** 1. FlowControlBar (primary zone), 2. CodeIntelControl (collapsible), 3. SpawnQueuePanel (queue + caps), 4. Active sessions list

### Style
- **Name:** Dark Mode (OLED)
- **Mode Support:** Dark only (Electron app — matches OS dark chrome)
- **Keywords:** Dark theme, low light, high contrast, deep black, developer tool, terminal aesthetic
- **Best For:** Electron developer tools, coding platforms, CLI orchestration panels, eye-strain prevention
- **Performance:** Excellent | **Accessibility:** WCAG AAA targets

*Notes: Dark bg + green positive indicators for running/success states. Match existing `var(--border)` token already in use.*

### Typography
- **Heading/Body:** JetBrains Mono (monospace — matches terminal/CLI aesthetic)
- **Mood:** terminal, cli, developer, precision, command-line
- **Best For:** Developer tools, orchestration panels, status monitors
- **Google Fonts:**
```css
@import url('https://fonts.googleapis.com/css2?family=JetBrains+Mono:ital,wght@0,400;0,500;1,400&display=swap');
```
- **Usage note:** Apply to section labels (`.sectionLabelPrimary`), meta labels, status text. Panel header "Command Center" uses weight 500.

### Key Effects
- Minimal glow on active/running states: `text-shadow: 0 0 8px var(--color-accent)`
- Border-based section separation (not box-shadow): `border-bottom: 1px solid var(--border)`
- Focus ring: `outline: 2px solid var(--color-ring); outline-offset: 2px`
- Subtle transition on collapse/expand: `transition: height 150ms ease-out`

### Spacing & Sizing (near-term targets)
| Token | Value | Usage |
|-------|-------|-------|
| `--space-1` | 4px | `.body` padding (currently hardcoded `4px`) |
| `--space-2` | 8px | `.body` padding (Step 9 target: `var(--space-2) var(--space-1)`) |
| `.btn` height | 30px / 26px | FlowControlBar primary/secondary (Step 7: bump from 28/24) |
| `.btn` `:disabled` | `opacity: 0.38; cursor: not-allowed` | FlowControlBar disabled state (Step 7) |
| `.sectionLabelPrimary` | `font-size: 10px; font-weight: 600; letter-spacing: 0.08em; color: var(--color-foreground)` | FLOW label (Step 3) |

### Interaction & Animation
- Collapse/expand (CodeIntelControl): 150ms ease-out; don't animate height directly — use max-height trick or CSS grid approach
- Button press feedback: `opacity: 0.75` on `:active`; restore to `1` on release (150ms)
- Disabled buttons: visual opacity reduction + semantic `disabled` attribute (RunnerBtn already wires `disabled={!enabled}`)
- Hover states on session rows: subtle background tint (`--color-muted`)

### Avoid (Anti-patterns)
- Mixing CSS px values outside the spacing scale (use `--space-*` tokens)
- Adding `border-bottom` to `.flowSection` when `FlowControlBar .wrapper` already has one — would double the separator line
- Applying `.sectionLabelMeta` to CodeIntelControl — it uses its own `.sectionToggle` class (do not duplicate)
- Icon-only buttons without aria-label
- Hover-only interactive states (panel is keyboard-navigable)

### Pre-Delivery Checklist
- [ ] No emojis as icons (use SVG: Lucide already in use)
- [ ] `cursor-pointer` on all clickable elements
- [ ] Hover states with smooth transitions (150–300ms)
- [ ] Dark mode text contrast 4.5:1 minimum
- [ ] Focus states visible for keyboard nav
- [ ] `prefers-reduced-motion` respected for collapse animations
- [ ] `.btn:disabled` rule in place (opacity + cursor)
- [ ] Single `border-bottom` separator between FlowControlBar and body (not doubled)

## North-Star: CLI Command Center Modal

Use flag `cliCommandCenterOpen` in `uiStore` (NOT `commandCenterOpen` — avoids collision with existing CommandCenter panel).

Component tree: `CliCommandCenter.tsx` → FLOWS column (`FlowCard`) + ENGINES column (`EngineCard` + `SpawnQueuePanel`)

Modal shell: `z-index: 950`; animate from the compact panel source (scale+fade, 200ms ease-out); Escape to close; backdrop click to close.
