## FAIL: Story S4.1 — cost_source value not surfaced in UI

**Criterion:** `cost_source` value is surfaced in the UI where cost is displayed (e.g. tooltip or badge: "estimated" / "provider reported" / "unpriced").

**What was expected:**
`AgentsTab` and `InspectTab` should display the `cost_source` string (e.g. a badge or tooltip showing "estimated", "provider reported", or "unpriced") alongside each cost figure.

**What actually happened:**
`computeCost()` in `costUtils.ts` returns a `CostResult` object with both `.cost` and `.source` fields. Both components call `computeCost()` but only consume `result.cost` — `result.source` is silently discarded at the call site. Neither component renders any badge, tooltip, or label for the cost source. The strings "estimated", "unpriced", and "provider_reported" do not appear anywhere in `AgentsTab.tsx` or `InspectTab.tsx`.

**Evidence:**
- `AgentsTab.tsx` line 34: `costUsd = result.cost` — `.source` not used
- `InspectTab.tsx` line 67: `sum += result.cost` — `.source` not used
- Grep confirmed zero occurrences of `result.source`, `estimated`, `unpriced`, `provider_reported` in either component file

**Files to fix:**
- `studio/src/renderer/src/components/DBExplorer/AgentsTab/AgentsTab.tsx`
- `studio/src/renderer/src/components/DBExplorer/InspectTab/InspectTab.tsx`

**Suggested fix (builder guidance):**
In `AgentsTab`, extend `AgentRow` to include `costSource: string | null`, populate it from `result.source` in `parseAgentDone`, and render a small badge or `title` attribute in the COST cell. In `InspectTab`, capture `result.source` per event and display an "unpriced" badge when `totalCost` is null rather than a generic `—`.
