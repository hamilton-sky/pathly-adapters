# Design System — differ-sections-fature-what-style-what-actions-w-2c50679e

> Generated by UI UX Pro Max · Stack: react (Electron) · 2026-07-01

## Query
Impact-aware artifact diff viewer with hunk sections, collapsible diff hunks, ImpactPanel blade showing code callers and affected flows, per-symbol caller count badges — for Pathly Command Center board (Electron desktop app)

## Design System Output

### Pattern
**Minimal + Documentation** — surface hierarchy designed for developer tooling.
- Primary surface: read-only code review panel (no form elements, no primary CTA)
- Layout: modal/overlay shell → split horizontal: `CodeDiffView` (left, ~60%) + `ImpactPanel` blade (right, ~40%)
- Blade slides in on hunk focus; closes with Escape or re-click; does not reflow the diff

### Style
**Dark Mode (OLED)** — matches Studio/Command Center's existing dark theme.

| Attribute | Value |
|---|---|
| Mode | Dark only |
| Performance | Excellent (OLED-optimized) |
| Accessibility | WCAG AAA capable |
| Feel | Developer tool — precision, low visual noise |

### Key Effects
- **Hunk separator**: `border-top: 1px solid var(--color-border)` + `background: var(--color-surface-elevated)` on hunk header row — visually separates hunks without heavy chrome
- **ImpactPanel blade entry**: `translateX(100%) → translateX(0)` slide-in, `duration: 220ms`, `ease-out` — spatial continuity (blade comes from the right edge)
- **Blade exit**: `translateX(0) → translateX(100%)`, `duration: 160ms`, `ease-in` — faster than enter
- **Focus ring**: `outline: 2px solid var(--color-focus-ring); outline-offset: 2px` on all keyboard-navigable elements
- **Badge hover**: `background` brightens from `--color-warning-dim` to `rgba(245,158,11,0.2)`, `transition: 150ms ease`
- **Reduced motion**: all slide/fade transitions collapse to `opacity 100ms` when `prefers-reduced-motion: reduce`

## Component Design Specs

### `ArtifactDiffViewer` — modal shell
- **Container**: fixed overlay, backdrop `rgba(0,0,0,0.55)`, blur `4px`
- **Panel**: `width: min(90vw, 1200px)`, `height: min(85vh, 900px)`, `border-radius: 8px`, `background: var(--color-surface)`
- **Header**: `height: 48px`, flex row; left = filename + `[surface a]` label; right = Escape `✕` button
- **Body**: flex row; `CodeDiffView` fills remaining space; `ImpactPanel` blade is `width: 360px` when open, `width: 0` when closed (CSS transition on width — use `max-width` transition to avoid reflow artifacts)
- **No footer** — surface (a) is read-only; omit the accept/reject bar present in `DraftDiffViewer`

### `CodeDiffView` — badge additions (new optional props only)
- **Hunk header row**: `background: var(--color-surface-elevated)`, `color: var(--color-muted-fg)`, `font-size: var(--font-size-sm)`, `padding: 4px 12px`
- **`⚠ N callers` badge** (rendered when `badgeFor(hunk) !== null`):
  - `background: var(--color-warning-dim)`, `color: var(--color-warning)`, `border: 1px solid var(--color-warning)30`
  - `border-radius: 4px`, `padding: 2px 6px`, `font-size: var(--font-size-xs)`, `font-weight: 500`
  - Placed right-aligned in hunk header row; `cursor: pointer`
  - Clicking calls `onHunkFocus(hunk)` — opens/refocuses the blade
- **No badge** when `badgeFor` returns `null` — hunk header renders unchanged
- File-header fallback badge: same visual treatment, placed in the diff's filename header bar

### `ImpactPanel` — blade
- **Structure**: vertical stack — blade header (title + close `✕`) → symbol list → affected flows section
- **Blade header**: `background: var(--color-surface-elevated)`, `border-bottom: 1px solid var(--color-border)`, `height: 44px`, `padding: 0 16px`; title = "Impact — `<filename>`"
- **Loading state**: skeleton rows — `background: var(--color-muted)`, `border-radius: 4px`, animated `opacity` pulse (1.0 → 0.5 → 1.0, `1.2s ease-in-out infinite`); respect reduced-motion (remove pulse, keep static skeleton)
- **`backendOff` state**: render `null` — blade is simply absent, no error shown (per PO constraint)
- **Symbol row** (`ImpactRow`): `padding: 8px 16px`; flex row: `<symbol-name> (monospace, sm)` left + `⚠ {N} callers` chip right; `border-bottom: 1px solid var(--color-border)30`
- **Callers list**: collapsible, toggle on symbol row click; indent `24px`; `font-size: var(--font-size-xs)`, `color: var(--color-muted-fg)`; `font-family: var(--font-mono)`
- **Affected flows section**: heading `font-size: var(--font-size-sm)`, `font-weight: 500`, `color: var(--color-muted-fg)`; flow name as plain text chip `background: var(--color-muted)`, `border-radius: 4px`, `padding: 2px 8px`
- **`activeHunk` highlight**: when a specific hunk is focused, the matching symbol row gets `background: var(--color-accent-dim)` + left border `3px solid var(--color-accent)`

### Diff line coloring

```css
.line-added   { background: var(--color-added-bg);   color: var(--color-added-fg); }
.line-removed { background: var(--color-removed-bg);  color: var(--color-removed-fg); }
.line-context { background: transparent; color: var(--color-foreground); }
.line-number  { color: var(--color-muted-fg); font-size: var(--font-size-xs); min-width: 40px; text-align: right; padding-right: 8px; user-select: none; }
```

### Graceful degradation states
| Condition | Behavior |
|---|---|
| `backendOff` (impact null) | `ImpactPanel` renders `null`; no blade; no badge; diff renders normally |
| Non-code artifact (markdown, JSON) | same as `backendOff` — no ImpactPanel; plain text diff |
| `git:blob` returns `null` (new file) | `originalText = ''`; diff shows all lines as added |
| `detect_changes` timeout / error | `useImpact` sets `backendOff: true`; graceful path above |

## Accessibility Checklist
- [ ] Keyboard: `Tab` navigates hunk headers and badge chips; `Enter/Space` opens ImpactPanel blade; `Escape` closes blade or entire modal
- [ ] Badge chip: `role="button"` + `aria-label="View impact: N callers affected"` — never icon-only
- [ ] ImpactPanel close button: `aria-label="Close impact panel"`
- [ ] Blade slide animation: wrapped in `@media (prefers-reduced-motion: reduce)` guard — skip translate, use only opacity 100ms
- [ ] Focus management: when blade opens, move focus to blade header; when it closes, return focus to the badge chip that triggered it
- [ ] Color alone never conveys diff meaning — added/removed use `+`/`-` gutter markers in addition to color
- [ ] Line numbers declared `aria-hidden="true"` (decorative)
- [ ] Contrast: foreground `#F8FAFC` on surface `#1E293B` → 12.6:1 (exceeds AAA)
