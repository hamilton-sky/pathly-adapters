> Generated by UI UX Pro Max · Stack: react · 2026-05-27

Chat panel stop/abort button and Claude Code proxy mode — stop LLM streaming mid-response and route chat messages to Claude Code PTY terminal

## Component Specs (UI UX Pro Max)

### Component 1 — Stop/Abort Button

**Icon:** `Square` from Lucide React, `size={14}`

**Color treatment (amber, not red):**
```js
// Amber signals "something is live / cancel available" without alarm
background: 'rgba(234, 179, 8, 0.15)',   // yellow-500 at 15%
color:      '#EAB308',                    // yellow-500
border:     '1px solid rgba(234, 179, 8, 0.3)',
// hover:
background: 'rgba(234, 179, 8, 0.25)',
```

**Pulse animation (border glow, not icon):**
```css
@keyframes stop-pulse {
  0%, 100% { box-shadow: 0 0 0 0px rgba(234, 179, 8, 0.4); }
  50%       { box-shadow: 0 0 0 4px rgba(234, 179, 8, 0.0); }
}
animation: stop-pulse 1.8s ease-in-out infinite;
```

**Send → Stop cross-fade transition (150ms):**
```css
/* Wrap both icons in position:relative container, overflow:hidden */
.send-icon, .stop-icon {
  position: absolute; inset: 0;
  display: flex; align-items: center; justify-content: center;
  transition: opacity 150ms ease, transform 150ms ease;
}
.send-icon         { opacity: 1; transform: scale(1); }
.send-icon.hidden  { opacity: 0; transform: scale(0.7); }
.stop-icon         { opacity: 0; transform: scale(0.7); }
.stop-icon.visible { opacity: 1; transform: scale(1); }
```

**Tooltip:** `"Stop generating"` · position: top-center · delay: 400ms

**Button must be ACTIVE (not disabled) when isLoading — user must be able to click it.**

### Component 2 — Mode Toggle (Chat LLM ↔ Claude Code)

**Layout:** Compact 2-segment pill with icon + short text label

**Icons:**
| Mode | Lucide Icon | Label |
|------|-------------|-------|
| Chat LLM | `MessageSquare` size 13 | "Chat" |
| Claude Code | `Terminal` size 13 | "Code" |

**Sizing:**
```js
// Pill container
height: 26, width: 118, borderRadius: 6, padding: 2,
background: 'rgba(255,255,255,0.05)',
border: '1px solid rgba(255,255,255,0.08)',

// Each segment
height: 22, minWidth: 57, borderRadius: 4,
fontSize: 11, fontFamily: 'Fira Sans',
padding: '0 8px', gap: 4,
```

**Active/Inactive states:**
```js
modeActive:   { background: t.accent, color: '#fff', fontWeight: 500 }
modeInactive: { background: 'transparent', color: 'rgba(255,255,255,0.45)' }
// hover inactive:
modeInactiveHover: { background: 'rgba(255,255,255,0.07)', color: 'rgba(255,255,255,0.7)' }
```

**Sliding indicator (smooth transition):**
```css
.indicator {
  position: absolute; top: 2px; bottom: 2px;
  width: calc(50% - 2px); background: t.accent; border-radius: 4px;
  transition: transform 180ms cubic-bezier(0.4, 0, 0.2, 1);
}
/* Chat mode: translateX(0) | Code mode: translateX(100%) */
```

**Footer placement (recommended):**
```
[ ModelSelector ]   [ model pill ]   [ Mode Toggle ]   [ Send/Stop ]
```
Group Mode Toggle + Send on the right — interaction controls cluster together; model info stays left as passive context.

**Tooltip:** "Chat LLM mode" / "Claude Code mode" · delay: 600ms

## Builder Notes

- Reference this file when implementing UI components for Conv 1 (stop button) and Conv 2 (mode toggle)
- Override any color that conflicts with existing `t.accent` / `t.bgSurface1` design tokens — prefer the project's existing tokens over the palette above
- Stack: react — use Lucide React for all icons, inline styles consistent with existing ChatInput.tsx pattern
- The amber stop-button color (`#EAB308`) is intentional — do NOT substitute red/destructive; red implies error state
- Send→Stop transition should use a cross-fade (opacity + scale), not a slide
- Mode toggle must use a sliding indicator div for the active segment, not toggling background colors per segment
- Checklist before shipping:
  - [ ] cursor-pointer on both interactive elements
  - [ ] Hover states with 150ms transitions
  - [ ] Focus states visible for keyboard nav
  - [ ] Stop button NOT disabled when isLoading (critical)
  - [ ] Mode toggle tooltip text matches spec above
