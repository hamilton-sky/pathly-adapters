# Design System — skill-notebook-editor

> Generated by UI UX Pro Max · Stack: React (Electron + Vite) · 2026-06-04

## Query
Jupyter-style skill notebook editor — three-panel layout with fragment catalog sidebar,
drag-and-drop prompt assembly notebook, and live assembled prompt preview panel for
building AI agent skills in Electron desktop app.

## Design Constraints (from architect + designer consultation)
- Dark theme app — existing tokens: `--bg-mantle` (#0B0F1A), `--bg-surface0` (#1E2433), `--accent` (#38BDF8)
- React + CSS Modules (no inline styles, no Tailwind)
- Three panels: Catalog (240px) | Notebook (flex) | Preview (320px)
- Two cell types: body (locked, sky-blue border) | fragment (draggable, green border)
- Native HTML5 DnD — no external library
- All components single-responsibility, max ~150 lines per file

## Design System Output

### Pattern
**App layout:** Three-panel IDE-style workspace. No conversion funnel — this is a tool panel.
Sections: Catalog rail | Notebook canvas | Preview pane

### Style
**Minimalism & Swiss Style** — clean, functional, high-contrast dark
- Mode: Dark ✓ Full
- Keywords: Clean, spacious, functional, high contrast, geometric, sans-serif, essential
- Best For: Professional developer tools, IDE panels, prompt editors
- Performance: ⚡ Excellent | Accessibility: ✓ WCAG AA

### Typography
**Space Grotesk** (headings/labels) + **system monospace** (preview content)
- Panel labels: 10px, semibold, uppercase, 0.06em tracking
- Cell titles: 13px, medium 500
- Descriptions: 11px, normal 400
- Category badges: 10px, semibold
- Preview body: 11px, `--font-family-mono` for code spans

### Key Effects
- Drag ghost: `opacity: 0.7`, follows cursor
- Drop pop: `scale(1.0→1.02→1.0)`, 150ms ease-out
- Insert zone reveal: `height: 6px → 32px`, 120ms ease-out (only during drag)
- Hover transitions: 120–200ms
- Preview debounce: 250ms after cell reorder

### Component Map

```
SkillNotebook/
  SkillNotebook.tsx           ← root 3-panel + resize state
  CatalogPanel/
    CatalogPanel.tsx          ← search + grouped fragment cards
    FragmentCard.tsx          ← single draggable card (grab cursor)
  NotebookPanel/
    NotebookPanel.tsx         ← cell list + insert zones + empty state
    BodyCell.tsx              ← locked section (sky-blue border, lock icon)
    FragmentCell.tsx          ← draggable/deletable (green border, ⠿ handle)
    InsertZone.tsx            ← invisible until drag active
  PreviewPanel/
    PreviewPanel.tsx          ← assembled prompt + variable input
    PreviewSection.tsx        ← section with [BODY]/[FRAG] origin badge
    ExportView.tsx            ← inline validation + confirm + success
  ResizeHandle.tsx            ← 4px drag divider between panels
```

### Avoid
- External DnD libraries (linear list = native HTML5 is sufficient)
- Inline styles
- Modal dialogs for export (use inline panel overlay)
- Raw markdown dump in preview (use structured section view)

## Builder Notes

- Map design tokens to existing `tokens.css` — do NOT add new color values, only semantic aliases
- `--cell-body-border: var(--accent)` and `--cell-fragment-border: var(--green)` as new semantic tokens
- All cell components live in their own subfolder with matching `.module.css`
- `InsertZone` height animates via CSS class toggle (not JS style prop) for `prefers-reduced-motion` support
- Fragment drag uses `draggable="true"` + `dragstart`/`dragover`/`drop` events
- Preview updates via debounced `POST /skills/preview` to FSM server (reuses `compose_skill()`)
- Stack: react — use `lucide-react` for icons (already in studio deps)
